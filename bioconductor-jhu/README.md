# Bioconductor for Genomic Data Science (JHU)

Notes and scripts for Kasper D. Hansen's *Bioconductor for Genomic Data Science*,
part of the JHU Genomic Data Science Specialization on Coursera. The course covers
the Bioconductor project for analyzing genomic data in R.

## Source

- Course materials: <https://kasperdanielhansen.github.io/genbioconductor/>
- Specialization: <https://www.coursera.org/specializations/genomic-data-science>

## Academic integrity

Graded assignments and quiz solutions are excluded from this repository
(see the repo-level `.gitignore`), per the Coursera Honor Code.
